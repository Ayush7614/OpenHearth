# @felix-ayush/openhearth-core

Shared audit engine for [OpenHearth](https://ayush7614.github.io/OpenHearth/).

Queries the GitHub Search API for pull requests, issues, and reviews; aggregates by repository; and computes feed-truncation insights.

Used by the `@felix-ayush/openhearth` CLI. Most users should install the CLI package instead.
